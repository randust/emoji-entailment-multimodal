# Emoji Entailment with Multimodal Learning

Multimodal NLP project investigating emoji-based textual entailment using
language models and visual representations of emoji compositions.

This project was developed as part of NUS CS4248.

## Project Repository

The original team project and implementation are included as a Git submodule:
